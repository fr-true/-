# 软件仓库（FR Hub）v3 · 项目详细介绍

---

## 一、项目定位

一套**开箱即用的软件下载分发平台**，面向软件站站长、资源分享社区、团队内部工具库等场景。安装向导引导式部署，无需数据库基础即可上线（JSON 模式），也可一键切换 MySQL。前台为移动端 APP 风格的毛玻璃单页应用，后台为完全独立的管理控制台。开发者：曾先生。

---

## 二、技术架构

### 2.1 技术栈

| 层面 | 选型 | 说明 |
| --- | --- | --- |
| 后端 | PHP 8.0+ | 无框架、零依赖、零构建 |
| 存储 | JSON 文件 / MySQL（PDO） | 安装时二选一，API 层完全无感 |
| 前端 | 原生 JS 单页应用（Hash 路由） | 无框架体积，首屏极快 |
| 样式 | 内联 CSS  | 深浅双主题一键切换 |
| 图标 | Font Awesome 6（BootCDN） | 全站唯一第三方图标库 |
| 重置样式 | normalize.css（BootCDN） | 仅此两个外部依赖 |
| 上传 | XHR 表单 + fileinfo 校验 | 实时进度百分比 |

### 2.2 数据抽象设计

所有数据读写只经过核心层的 `frLoad(name)` / `frSave(name, data)` 两个函数：

- **JSON 模式**：读写 `frData/*.json`，`flock` 文件锁保证写入安全
- **MySQL 模式**：文档式存储于 `fr_store` 表（`fr_key` 主键 + `fr_val` LONGTEXT + `fr_updated` 更新时间），安装时自动建库、建表
- 两种模式可随时互迁：导出 JSON 数据 → 修改 `frEnv.php` 的 `driver` → 重新导入即可

### 2.3 文件结构

```
install.php    引导安装向导（安装完成后自动锁定，建议删除）
frCore.php     公共核心：存储抽象层、上传处理、日志、统计、防爬、种子数据
frEnv.php      安装生成的环境配置（存储引擎、数据库凭据、时区）
index.php      前台：页面 + 前台 API（登录注册/收藏/评论/下载/投稿/头像上传）
admin.php      后台：独立控制台 + 后台 API（前台无任何入口，已 noindex）
fr.png         默认打赏码占位图（后台上传收款码后以配置为准）
frData/        JSON 模式数据目录（运行时自动生成）
frUploads/     上传文件目录（自动创建，含 .htaccess 加固与 index.html 防列目录）
README.md      部署文档
```

## 三、引导安装向导（`/install.php`）

毛玻璃卡片式分步界面，顶部步骤进度条，深浅双主题，移动端自适应。共六步：

| 步骤 | 内容 |
| --- | --- |
| 1 · 欢迎 | 功能亮点卡片：双存储引擎、图片上传体系、演示数据、环境自检 |
| 2 · 环境检测 | 自动体检：PHP≥8.0（必检）、JSON 扩展（必检）、Mbstring（必检）、PDO MySQL（选检）、Fileinfo（上传强校验）、服务器上传限额展示、目录写权限（必检）。必检不通过则阻断下一步 |
| 3 · 存储方式 | 卡片单选 JSON / MySQL；选 MySQL 展开连接表单（主机/端口/库名/前缀/用户/密码），支持**测试连接**，通过后自动建库，必须测试通过才能继续 |
| 4 · 站点与管理员 | 网站名称、标语、SEO 关键词、描述、ICP 备案号、联系邮箱、页脚说明、时区（7 个常用时区）；管理员账号（3-16 位字母数字下划线）+ 密码二次确认，**不再有任何默认密码** |
| 5 · 高级选项 | 注册/评论/签到/下载四项积分规则、防爬限流阈值（次/10秒）、上传大小限制（1-10 MB）、防爬开关、投稿开关、演示数据开关（12 款示例软件 + 演示用户 + 评论 + 14 日统计曲线） |
| 6 · 安装 | 四阶段进度动画：写入环境配置 → 初始化存储引擎 → 导入基础数据 → 完成安装；成功后展示前台/后台入口卡片与安全建议 |

安装动作：写入 `frEnv.php` → 建库建表（MySQL 模式）→ 写入站点配置（含密码哈希）→ 按开关导入种子数据 → 创建并加固 `frUploads` 目录。**安装完成后 `frEnv.php` 存在即锁定安装页**，重装需手动删除该文件。

## 四、前台功能详解（`index.php`）

Hash 路由单页应用：`#/` 首页、`#/list` 软件库、`#/app/{id}` 详情、`#/mine` 个人中心、`#/submit` 投稿。

### 4.1 首页

- **轮播图**：自动播放（4.6 秒）、左右箭头、指示点、手势滑动（Pointer 事件）、鼠标悬停暂停；支持后台上传的背景图（自动叠加深色遮罩保证文字可读）或主题色渐变
- **滚动公告**：多条公告垂直轮播动画，点击打开公告详情弹窗，后台可置顶排序
- **搜索区**：毛玻璃大搜索框 + 分类横向滚动芯片，回车即搜
- **热门下载**：下载量 TOP6 卡片，前三名带金/银/铜 TOP 角标
- **最新更新**：按更新时间排序的最新 8 款
- **排行榜**：下载榜 / 收藏榜 / 好评榜一键切换，行式列表带名次着色
- **投稿 CTA**：渐变卡片引导投稿（后台可关闭）

### 4.2 软件库

- 分类筛选（全部 + 7 个分类芯片）+ 排序段控件（热门/最新/评分）+ 关键词搜索（防抖 420ms）
- URL 参数化：`#/list/cat-2_sort-rating_q-关键词`，可直接分享筛选结果
- 加载骨架屏、分页「加载更多」、空状态插画卡

### 4.3 软件详情页

- **头部卡**：软件图标（图片图标优先）、名称、开发者、版本、大小、星级评分、浏览/下载/收藏统计，置顶徽标
- **操作区**：立即下载、收藏/取消收藏、分享（复制链接 + 伪二维码 + 社交平台）、举报（弹窗提交原因入日志）
- **截图画廊**：后台上传了真实截图则横向滚动展示真实图（懒加载、滚动吸附）；未上传则渲染**主题色模拟截图**（渐变底 + 拟真界面元素），保证视觉不空
- **软件介绍**：富文本段落渲染，`-` 开头自动转为带勾选图标的列表项；标签芯片展示
- **版本信息表**：版本/大小/分类/更新时间/首发时间/授权
- **下载渠道卡**：多镜像列表（官方镜像/电信线路/备用下载），点击直达下载流程
- **评论区**：星级输入（可点选 1-5 星）、评论提交后进入**审核队列**（自己的待审评论带「审核中」徽标实时可见）、已通过评论列表、未登录展示登录引导条
- **相关推荐**：同分类下载量最高的 4 款
- **打赏卡片**：侧栏直达打赏弹窗

### 4.4 下载流程（核心炫酷交互）

1. 弹窗选择下载线路（单选镜像卡，展示地址与可用状态）
2. 点击开始 → **节点匹配倒计时 3-2-1**（环形进度背景 + 数字弹跳动画）
3. **进度条模拟传输**：百分比 + 随机速率（6-14 MB/s）+ 阶段提示（加密连接 → 校验签名 → 高速传输 → 即将完成）
4. 完成态打勾动画 → **自动打开真实下载链接**（弹窗拦截时可点击按钮重试）
5. 后台静默写入下载统计：软件下载次数 +1、下载记录入库、今日/累计下载统计更新；若配置了下载消耗积分则校验并扣减

### 4.5 用户体系

- 注册（昵称 2-12 字 + 邮箱格式校验 + 密码 ≥6 位 + 唯一性校验，注册赠送积分）/ 登录（用户名或邮箱）
- **个人中心**：头像（支持上传更换，带进度提示）、昵称、积分徽标、每日签到（防重复，奖励积分）、退出登录（确认弹窗）
- 四个数据页签：我的收藏（软件卡片网格）、下载记录（时间线列表）、我的评论（含审核状态徽标）、我的投稿（含审核进度）

### 4.6 投稿

登录后填写：软件名称、版本号、分类、官网链接、推荐理由（≥10 字）。提交成功弹出**三步时间线弹窗**（已提交 → 安全审核 → 精选上线）。后台审核通过后自动生成软件草稿（默认下架）并奖励投稿者 10 积分。

### 4.7 打赏

页脚、详情页侧栏均可唤起打赏弹窗：伪二维码底纹 + `fr.png` 或**后台上传的收款码**覆盖展示、金额快捷芯片、提示文案根据图片来源自动切换。

### 4.8 通用体验

- **开屏动画**：品牌图标脉冲光环 + 进度条，数据就绪后淡出
- **骨架屏**：列表/详情加载时灰色微光占位
- **滚动进场**：`IntersectionObserver` 驱动卡片上浮显现，尊重系统减弱动效设置
- **Toast 通知系统**：成功/警告/错误三种语义，上传时变为百分比进度条
- **弹窗栈管理**：毛玻璃遮罩 + 弹性入场，Esc 关闭、点遮罩关闭、移动端自动变为底部抽屉
- **移动端**：底部四键毛玻璃导航栏（首页/软件库/投稿/我的），导航栏压缩，安全区适配

## 五、后台功能详解（`admin.php`）

独立入口（前台无任何链接，页面 `noindex`），管理员登录页带错误抖动动画。左侧毛玻璃侧边栏（移动端抽屉式），十个功能模块：

| 模块 | 能力 |
| --- | --- |
| 数据看板 | 8 张统计卡（今日/总访问、今日/总下载、用户数、软件数、待审评论、待审投稿）；近 14 日访问趋势柱状图（CSS 渲染，悬停提示数值）；下载排行 TOP5；最近操作日志流；侧边栏实时角标提示待审数量 |
| 软件管理 | 关键词搜索；表格展示图标/名称/分类/下载量/评分；**置顶开关**、**上架下架开关**（拨动组件即时生效）；编辑弹窗：名称、分类、开发者、版本、大小、**图片图标上传**（预览 + 移除回退矢量）、27 个矢量图标选择器、双色相滑杆（实时渐变预览）、标签、一句话简介、详细介绍、**截图上传（最多 8 张，多选 + 拖拽 + 缩略图删除）**、多下载链接（每行 `名称|地址`）；删除联动清理评论 |
| 分类标签 | 增删改、图标选择、实时统计各分类软件数、有软件的分类禁止删除 |
| 轮播管理 | 增删改、渐变预览缩略图、**背景图上传**（预览 + 移除回退渐变）、角标文案、跳转地址、置顶开关 |
| 公告管理 | 增删改、置顶、时间记录 |
| 评论审核 | 全部/待审核/已通过/已驳回四态筛选；展示用户头像、所属软件、星级、内容、时间；通过（**自动奖励评论积分**）/ 驳回 / 删除 |
| 用户管理 | 头像、昵称、邮箱、积分（快捷 ±10 调整）、注册时间、状态；停用/恢复（停用后无法登录）、删除 |
| 投稿审核 | 提交人、名称、版本、分类、理由、来源链接直达；通过 → **自动生成待上架软件草稿**并奖励 10 积分；驳回 |
| 操作日志 | 全站行为审计（登录/注册/评论/下载/投稿/举报/上传/后台操作），时间、操作人、动作徽标、详情、IP；一键清空（二次确认） |
| 网站配置 | 基础信息（名称/标语/SEO/描述/备案/页脚/邮箱）；积分规则四项；防爬开关、投稿开关、限流阈值、**上传大小限制**；**打赏收款码上传**（即时生效 + 恢复默认）；管理员账号与改密 |

后台所有弹窗均为毛玻璃样式，删除类操作全部二次确认，表单保存即时 Toast 反馈。

## 六、图片上传体系（v3 核心）

| 上传位 | 用途 | 权限 | 回退方案 |
| --- | --- | --- | --- |
| 软件编辑器 · 图标 | 图片图标优先展示 | 管理员 | 矢量图标 + 双色相渐变 |
| 软件编辑器 · 截图 | 详情页截图画廊（≤8 张） | 管理员 | 主题色模拟截图 |
| 轮播编辑器 · 背景图 | 首页轮播背景 | 管理员 | 渐变色 + 装饰圆 |
| 网站配置 · 收款码 | 打赏弹窗二维码 | 管理员 | 根目录 fr.png |
| 个人中心 · 头像 | 用户头像（评论区同步） | 登录用户 | 昵称首字 + 色相头像 |

**安全链路**（四层防护）：

1. 扩展名白名单：仅 `jpg / jpeg / png / gif / webp`
2. fileinfo 读取真实 MIME，拒绝改后缀的伪装文件（无 fileinfo 时降级为 getimagesize 校验）
3. `getimagesize` 验证图片有效性，最长边限制 4000px
4. 存储路径白名单正则校验（`frUploads/年月/类型_日期_哈希.扩展名`），数据库层面拒绝任意外链注入；`frUploads/.htaccess` 禁止脚本执行与目录浏览，`index.html` 兜底

**体验**：XHR 上传实时百分比 Toast、拖拽放入截图上传区、缩略图即时预览、逐张队列上传、单张移除。上传大小上限 1-10 MB 可配置（受服务器 `upload_max_filesize` 约束，安装向导环境检测页会明示当前限额）。

| 行为 | 默认值 | 说明 |

## 八、安全设计汇总

| 维度 | 措施 |
| --- | --- |
| 密码 | `password_hash` / `password_verify`（bcrypt），安装时自设管理员密码，无默认密码 |
| 后台隔离 | 独立入口、前台零链接、`noindex`、会话鉴权、所有后台 API 401 拦截 |
| 防爬 | 可开关：拦截常见脚本 UA（curl/python/scrapy/spider 等）+ 会话级 10 秒窗口限流（阈值可配），超限返回 429 |
| 上传 | 四重校验（见上节）+ 上传目录脚本执行封禁 |
| 输出 | 全站 `frEsc` HTML 转义，评论/投稿等用户内容防 XSS |
| 数据 | 文件写入 `flock` 排他锁；MySQL 预处理语句防注入 |
| 安装 | 安装后安装页自动锁定；`frEnv.php` 为 PHP 返回数组（直接访问无输出） |
| 审计 | 操作日志记录登录、增删改、上传、举报等全链路行为与 IP |

## 九、UI 设计规范

- **毛玻璃体系**：导航、卡片、弹窗、底部栏统一 `backdrop-filter: blur(20px) saturate(1.5)`
- **双主题**：浅色 `#f3f4fa` 底 / 深色 `#0e1016` 底，跟随系统偏好初始化，手动切换持久化，前台后台安装页三端共享同一主题键
- **主色克制**：主色靛蓝 `#5b6cff` + 辅助青绿 `#18c0b2`，仅两个主色；语义色（成功/警告/错误/星级）为功能色
- **圆角与阴影**：卡片 18px、按钮 12px、芯片全圆；柔和浅阴影 `0 10px 30px rgba(25,28,38,.08)`
- **字号梯度**：`clamp(22-30px) / 19 / 16 / 14 / 12` 五级
- **移动端优先**：底部导航、抽屉弹窗、双列卡片、横向滚动画廊、安全区适配
- **无障碍**：`aria-label`、`role`、`focus-visible` 焦点环、`prefers-reduced-motion` 动效降级、弹窗焦点与 Esc 管理

## 十、部署方式

**本地快速体验**

```bash
php -S 0.0.0.0:8080
# 浏览器访问 http://127.0.0.1:8080/install.php
```

**生产环境**：放入 Apache / Nginx 的 PHP 8.0+ 站点目录，确保站点根目录与 `frData`、`frUploads` 可写；Nginx 建议追加：

```nginx
location ~* ^/frUploads/.*\.(php|phtml|phar)$ { deny all; }
```

**重装**：删除 `frEnv.php` 后重新访问 `/install.php`（JSON 模式可一并清空 `frData/`）。

## 十一、常见问题

| 问题 | 处理 |
| --- | --- |
| 上传提示超出服务器限制 | 调大 `php.ini` 的 `upload_max_filesize` 与 `post_max_size`，环境检测页可查看当前值 |
| MySQL 模式连接失败 | 确认账号具备 CREATE DATABASE 权限；或手动建库后填写已存在的库名 |
| 忘记管理员密码 | 删除 `frEnv.php` 与数据后重装，或手动修改存储中 config 的 adminPass 哈希 |
| 前台打开是空白跳转安装页 | 属于未安装状态，访问 `/install.php` 完成向导即可 |
| 高并发场景 | JSON 模式适合中小站点；更大流量建议 MySQL 模式 + Nginx 层限流 + OPcache |
